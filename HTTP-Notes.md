# HTTP Notes

## GET

Used to receive information from a server.

Example:

Browser -> Google

Request:
GET /index.html

The server sends data back.

---

## POST

Used to send information to a server.

Example:

Login Form

Username

Password

↓

POST

↓

Server

---

## HTTP Status Codes

### 200 OK

Everything worked correctly.

---

### 301 / 302

Redirect.

The page moved.

---

### 400

Bad Request.

---

### 401

Unauthorized.

---

### 403

Forbidden.

---

### 404

Page not found.

---

### 500

Internal Server Error.
