
## Layer 7 - Application

Examples:
- Web Browser
- DNS
- Email

This is the layer users interact with.

## Layer 4 - Transport

Protocols:
- TCP
- UDP

Responsible for data transport.

## Layer 3 - Network

Contains:
- IP Address

Responsible for routing packets between networks.

## Layer 2 - Data Link

Contains:
- MAC Address

Responsible for communication within the local network.

## Layer 1 - Physical

Examples:
- Ethernet Cable
- Wi-Fi Signal
- Fibre Optic Cable

Responsible for transmitting bits.

## Quick Revision

- Layer 7 = Applications and DNS
- Layer 4 = TCP / UDP
- Layer 3 = IP Address
- Layer 2 = MAC Address
- Layer 1 = Physical connection
