# Networking Notes

## IP Address
- Identifies where a device is located on a network.
- IP addresses can change.

## MAC Address
- Identifies the physical network adapter.
- Usually assigned to the network interface.
- Used within a Local Area Network (LAN).

## MAC Spoofing

- Changing a MAC address to impersonate another device.

### Security Note
- A MAC address alone is not sufficient network security.

## Ping
- Uses ICMP.
- Tests network connectivity.
- Measures latency.
- Shows packet loss.
- Checks whether a host is reachable.

## ICMP
- Internet Control Message Protocol.
- Used by Ping.
- It is not TCP or UDP.

## Quick Revision

- IP = where you are.
- MAC = who you are on the local network.
- Ping = checks if a device is responding.
- ICMP = protocol used by Ping.
- MAC Spoofing = impersonating another MAC address.
